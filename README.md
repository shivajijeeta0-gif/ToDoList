# AuraFlow — Cherry Blossom Rituals

This is a static single-file AngularJS-based To-Do / rituals page styled with a cherry-blossom theme.

Features:
- Ambient falling petals and windstorm transition
- LocalStorage persistence for tasks
- Simple metrics dashboard and filters

How to publish with GitHub Pages

1. Ensure this folder is committed to a Git repository connected to `https://github.com/shivajijeeta0-gif/ToDoList`.
2. Push the `index.html` (root) to the `main` branch.
3. In the repository Settings → Pages, set Source to `main` branch and folder `/ (root)`.
4. After a minute the site will be available at:

   `https://shivajijeeta0-gif.github.io/ToDoList/`

If you want, enable automatic deployment via GitHub Actions or I can add a simple workflow file for you.
